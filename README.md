# 小小商队 LittleCaravan

林潇的校招 / 实习成果项目。

- [在线展示](https://lx1454641058-source.github.io/little-caravan/showcase/)
- [全部作品](https://lx1454641058-source.github.io/lin-xiao-portfolio/)

当前展示方式：浏览器在线试玩。

## 问题与本人责任

围绕城镇贸易、背包装载和旅途决策建立循环。本人拆解玩法与需求，整理规则、页面和交付条件，借助 AI 推进网页与 Windows 内部试玩版本，并跟进存档和重复操作问题。

## 具体任务 1：把交易拆成规则

定义货物占地、相邻加成、品质损耗、路线时间和费用；区分普通出售与整单交付，明确货物、数量、目的地、期限与搭配条件。处理迟到、到达和奖励领取状态。

## 具体任务 2：设计成长与反馈

推进三城活动、小游戏、收藏和营地成长；整理返回地图、物品详情、订单条件入口。小游戏可跳过或退出，失败不扣原有资源，未结算奖励不提前发放。

## 具体任务 3：保护已有进度

区分当前旅程和跨程成长，核对一次性奖励与重复操作；跟进旧版存档升级、备份、恢复和多窗口冲突，保留版本说明与问题记录。

## 成果与面试演示

已有可玩网页、Windows 内部试玩包和版本 / 存档恢复说明。建议演示一张订单从接取到交付，再展示奖励和保存状态。本次已提供公开案例展示页；未完成 Steam 提审、正式发行或商业收益验证。

## 查看与运行

安装 Node.js 后运行 `npm run preview`；也可直接打开在线试玩。公开版本仅包含浏览器游戏，不分发 Electron 运行时。

仅发布整理后的成果说明和项目源码副本，不包含私人历史、凭据、模型权重、数据库、第三方游戏或运行时。现有第三方许可记录保留；未声明整体许可证的原创代码不新增许可证，请勿据此视为获得商业再分发授权。
